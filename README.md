# ReproRehab 2026 – Pod 1 Website

This repository contains the supporting materials used to maintain the **ReproRehab 2026 Pod 1** website and participant resources.

While the shared **ReproRehab Pod 1** repository houses course code, examples, and reproducible research materials, this repository serves as the home for the GitHub Pages site that organizes links, resources, and information used throughout the year.

## Repository Contents

- **`index.qmd`** – Source file for the Pod 1 webpage
- **`index.html`** – Rendered webpage served through GitHub Pages
- **`images/`** – Images used on the website
- **`index_files/`** – Supporting files generated during rendering

The live website is available at:

**https://madelineratoza.github.io/2026Pod1/**
