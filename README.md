# ReproRehab 2026 Pod 1 Website

This repository contains the source files for the ReproRehab 2026 Pod 1 website, which is hosted using GitHub Pages.

The site provides participants with a central location for course resources, announcements, and links used throughout the year.

## Contents

- `index.qmd` – Source page written in Quarto
- `index.html` – Rendered webpage served by GitHub Pages
- `images/` – Images used on the website
- `index_files/` – Supporting files generated by Quarto

## Updating the Site

After editing `index.qmd`, render the page:

```bash
quarto render index.qmd
```

Then commit and push the updated files to GitHub.
